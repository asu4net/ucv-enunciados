# Ejercicio 1
Creamos un suelo con la textura correspondiente que elijamos, luego dos personajes, un jugador y un enemigo. Para ambos crearemos dos tipos de script:

- Movimiento: Queremos que este script tenga un atributo (visible en el editor de Unity) de velocidad y otro de dirección. Probarlo en ambos personajes usando valores distintos de velocidad y dirección.

- Escala: En este script queremos que los personajes modifiquen su escala, también habilitar atributos editables para cambiar la velocidad y si se está aumentando o disminuyendo de tamaño (podéis usar un float 1/-1 para crecer/decrecer)

Opcional: No es obligatorio, pero en el escala podría estar interesante que crezca hasta cierto punto y luego decrezca, creando un efecto como si estuviera pulsando.
